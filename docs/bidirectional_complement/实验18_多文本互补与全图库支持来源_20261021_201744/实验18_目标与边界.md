# 实验18：多条文本互补，而非选出唯一T2

目的：同身份不同描述之间的可靠互补与有害拒绝；之后单独研究多图互补；最后研究图文互补。
训练身份内A查询文本/B文本支持图/C评价图三组图像不重叠。
Top16只是局部辅助，visual_anchor_expand从局部向外扩展，visual_global在整个B图库独立成组并选择。
固定总beta=.25(来自实验12设置)，比较1/2/4个不同训练caption，尽可能优先不同图像来源。
PID Reference只有教师参考意义；任何官方Val/Test人工caption不得成为B支持。
当前验证的是多文本数量、支持来源与排序效用代理；尚未验证真正语义可靠性或正式单文本R1提升。

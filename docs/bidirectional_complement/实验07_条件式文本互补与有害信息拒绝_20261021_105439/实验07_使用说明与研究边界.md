# 实验07：条件式多文本互补与有害信息拒绝

## 两个同等重要的目标
1. 对确实有用的同身份补充文本，学会接受和使用。
2. 对损害检索匹配的支持文本，学会拒绝；不确定时不强行补全。

## 协议
- Train PID: 支持集构建、教师评分器及监督，可使用真实身份。
- 内部未见 Train PID: 只做标明 Oracle 的教师三分类诊断。
- Val: 当前查询和每张候选图像独立打分，禁止使用 Val PID 或其他同身份文本。
- 先用原始冻结 IRRA 从完整图库生成固定 Top-K 再重新打分；完整图库计算 R1/R5/R10/mAP/mINP。
- 不与原始 IRRA 的单向量检索效率混为一谈：本研究为候选图像条件重排。

## 代理标签与限制
- useful / harmful / uncertain 来自带有训练 PID 的正图与困难负图上的分数变化。
- 这些不是人工确认的语义属性真值；教师门控的分类分数不能当最终检索能力。
- WrongPID 角度匹配教师复用了真实教师的接受/拒绝掩码：隔离教师更新方向，不是彻底无身份信息的独立门控。
- reg_shuffle 则打乱接受/拒绝标记，作为模型容量和门控监督的额外负对照。
- 未通过有益接受与有害拒绝的两项指标，则不要宣称可靠性门控成功。
- 任何新机制的检索收益都应与无支持监督、普通正则化、错误身份进行比较。
- Val 已反复用于研究；固定机制后才在独立 Test 评估。

## 运行
首次：在 PyCharm 直接运行；检查：--self-test；中断恢复：--resume。
全部输出放在本实验目录，发送给ChatGPT.zip 排除大型 npy 与权重。

# 实验19：寻找同身份多文本集合的可靠来源（不做文本融合）

目标：图像成组纯度和文本T1到身份组归属分别评价。全图库成组，无须先进入Top16。
Train 1760 PID分4折训练并crossfit校准拒识阈值；440 PID独立评估归属模型。
每个身份Train图像C独立保留但绝不用于选组或模型拟合；A给T1，B给图像+已有训练描述。
真实PID只用于离线拟合标签和事后核查；holdout候选生成、选组不读取真实PID。
输出一个身份组可提供的多张图像和所有不同TRAIN描述，不强制只选一条T2。
Val/Test的人工图库文字不得被模型用于推理；本实验未得到正式Validation检索提升。
本实验不包含Huffman树、不包含最短路径算法；这些仅作后续方法讨论。

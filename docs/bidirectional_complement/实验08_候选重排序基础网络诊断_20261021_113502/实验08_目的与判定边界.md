# 实验08：基础重排序故障归因

- 本实验无多文本教师、无可靠性文本选择训练，属于基础网络专项诊断。
- 直接使用实验07原始Warmup权重和同一AdamW优化器状态；训练Fit PID、困难负样本、训练顺序一致。
- 先重放原始预测，测量把分数修正从1缩小到0时检索怎样变化，避免把评分失真说成过拟合。
- 五个单因素训练对照：完全重放、后续低学习率、更强修正保护、固定Gate、硬限制修正幅度。
- 真实是否过拟合只能对比训练与内部未见Train身份的表现，不能凭一次Val下降断定。
- 指标为原始IRRA固定TopK候选重排后的完整图库检索；检索分数不使用Val PID。
- 不得用已多次开发使用的Val最优模型当作独立Test性能。

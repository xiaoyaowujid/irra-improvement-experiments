# 实验16：同身份不同文本的可获取性

唯一当前研究目标：有益同身份T2可接受，有害T2可拒绝，最终改善正式单文本检索。
本步只检查Top16是否形成真实多图候选以及无标签图像分组能否稳定。
该步仅准备补充文本的合法来源，不训练文本学生，不做图像互补，更不做联合图文互补。

### 推理合法性
Top16采用单条Val T1特征；组内相似度只来自候选图像特征。Val真实PID只作分组完成后的评价，绝不参与分组。
禁止把官方Val图像原有的人工caption当作推理可得的T2。当前无可部署的图像描述生成器或合法图库描述库，故可用真实同身份T2=0。
TRAIN caption在训练内部可用于教师实验，但不是Val画廊的可用标注。
预计下一步先核查描述来源的合法性和事实准确性，再调用已有实验15选择机制。

# 实验13：实验12筛选器接受/拒绝与第三视角真实收益

主问题：被拒绝的同PID真实T2，是否在第三张同身份图像C上其实有帮助？

完全复用实验12的440个Train holdout PID、同PID不同图像T2与固定种子、筛选器和阈值、T1选定的固定负样本D、融合系数beta。C只用于选择后的事后评价。

潜在收益 = [(T1+T2)·C - (T1+T2)·D] - [T1·C - T1·D]，各融合特征均归一化。

分组报告接受组/拒绝组中的边际改善、恶化、零变化、转正、转错，并按PID簇bootstrap。
有益/有害的定义是固定D上的判别边际变化，不等于T2的语义事实正确/错误。
没有训练新模型，不改变原IRRA与实验12筛选器，不检索Val/Test，不做阈值调参。
本研究诊断“漏掉有益文本”的潜在问题，不直接证明新检索方法R1提升。

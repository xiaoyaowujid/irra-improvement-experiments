# IRRA 改进实验归档：哪些改了有效，哪些改了没用

本仓库归档我在 **IRRA**（Text-to-Image Person Retrieval, CUHK-PEDES）上做的一轮系统化改进实验。
共 **100+ 组变体、7 轮发散探索 + 17 步硬负样本迭代 + 23 个图文双向互补实验**，这里只保留有两类价值的部分：

- **有效实验**：在官方 val 上可复现的指标增益（有随机对照、多种子或跨轮复现支撑）；
- **反例**：曾经看起来有希望、最终被证伪的方向，以及它们错在哪。

> 一句话结论：**真正稳定有效的只有两类** —— ① 推理侧的**全查询 OT / Sinkhorn 平衡**（R1 +1.51，三轮独立复现）；
> ② 训练侧的**「错排驱动硬负样本 + 已正确排序保护」**（R1 +0.59，且在从未参与选模的冻结 Test 上独立确认 +0.14 ~ +0.21）。
> 而花了最多时间的「图文双向互补 / 多文本描述」路线，看似有 +2 点增益，**却被随机文本对照直接打平**，核心假设被证伪。

## 1. 实验协议

| 项目 | 设置 |
|---|---|
| 数据集 | CUHK-PEDES（Text-to-Image 行人检索） |
| 基线 | IRRA 官方复现，`logs/CUHK-PEDES/20261009_095215_irra_baseline_b8_resume20`，**Epoch 58** |
| checkpoint SHA256 | `f3ab12028e3406546b836ed6a75c8fc5e02a42146c5da13af423e7f5cf0e7ea6` |
| val 规模 | 6158 queries / 3078 gallery images / 1000 PIDs |
| 指标 | R1 / R5 / R10 / mAP / mINP（%） |
| 基线 val | **R1 66.418 / R5 85.271 / R10 90.581 / mAP 61.866 / mINP 47.251** |
| 基线 test | **R1 66.374 / R5 85.689 / R10 90.919 / mAP 61.447 / mINP 47.064** |

三条纪律：

1. **Test 只在最后用一次**。除 B3 的独立验证外，所有选择都在 val 上完成，Test 指标不参与任何调参。
2. **训练侧必须三种子**（42/43/44）报均值；单种子增益一律不采信。
3. **必须有随机对照**。同算力、同预算的随机负样本（`B1_random`）作为对照臂，用来排除「只是多训了 800 步」的解释。

## 2. 有效实验（一）：推理侧全查询 OT 平衡 —— 最强单项增益

在**不训练、不改模型权重**的前提下，只对测试时的相似度矩阵做一次全局平衡。核心观察：IRRA 的 top-1 错误里有相当一部分是**「多查询抢同一张图」**造成的，而不是特征本身不可分。

| 方法 | R1 | ΔR1 | ΔmAP | ΔmINP | 复现情况 |
|---|---|---|---|---|---|
| **O_全查询低温 Sinkhorn（OT 平衡）** | **67.928** | **+1.510** | +1.195 | +1.435 | 第 5/6/7 轮三次独立复现，数值完全一致 |
| R_列 LogSumExp 全强度 | 67.749 | +1.332 | +1.036 | +1.269 | 第 6 轮 |
| O_非均匀图库容量 | 67.506 | +1.088 | +0.962 | +1.313 | 第 7 轮 |
| O_部分列平衡 | 67.441 | +1.023 | +0.841 | +0.940 | 第 7 轮 |
| R_列 LogSumExp 半强度 | 67.408 | +0.991 | +0.804 | +0.999 | 第 6 轮 |
| E2_等权视觉翻转融合 | 66.970 | +0.552 | +0.379 | +0.440 | 第 2/3/4 轮三次复现 |
| E5_一致性自适应翻转 | 66.921 | +0.503 | +0.372 | +0.441 | 第 2 轮 |
| E7_双视图 Max 融合 | 66.872 | +0.455 | +0.286 | +0.380 | 第 3 轮 |
| G5_原始 IRRA Top1 竞争抑制 | 66.824 | +0.406 | +0.042 | −0.003 | 双向邻近图第二轮 |
| R_列方差标准化 | 66.807 | +0.390 | +0.233 | +0.329 | 第 6 轮 |

**为什么可信**：O 系列在第 5、6、7 三轮里作为「历史增益复核」被重复跑了三次，三次指标**逐位一致**（R1 = 67.927899），说明这不是运气。同时 `net_correct = +93`（修正 213、破坏 120），修正是破坏的 1.8 倍，不是靠交换错误换来的。

**必须说明的局限**：OT 平衡是 **transductive** 的 —— 它用到了「整批查询」的分布统计。如果你的应用是单条查询在线检索，这个方法**不能直接用**；它适用于离线批量评测或整库重排场景。我把它和 transductive 对照臂 `B1_val_batch_reference`（+0.942）并列放在 `results/summary_all.csv` 里，后者仅作对照，**不算方法**。

## 3. 有效实验（二）：训练侧「错排驱动硬负样本 + 排序保护」—— 唯一通过 Test 独立验证的改进

出发点是 IRRA 的对比学习只采样**随机**负样本，而真实错误主要来自「差一点点」的**同性别、同体型、同衣着风格**的硬负样本。但单纯挖硬负样本会崩（见反例），关键在于**保护已经排对的查询**。

| 方法 | α | R1 | ΔR1 | ΔmAP | ΔmINP | 修正/破坏 |
|---|---|---|---|---|---|---|
| **P1_已正确排序保护** | 1.0 | **67.002** | **+0.585** | +0.532 | +0.687 | +173 / −137 |
| **S1_同身份特征空间混合** | 1.0 | 66.970 | +0.552 | **+0.589** | **+0.833** | +178 / −144 |
| W1_错排纠正 + 正确排序保护 | 0.5 | 66.970 | +0.552 | +0.532 | +0.641 | +143 / −109 |
| W2_停止间隔 + 有界梯度纠错 | 1.0 | 66.910 | +0.493 | +0.487 | +0.685 | +204 / −174 |
| H2_错排 + 半硬负样本 | 0.5 | 66.878 | +0.460 | +0.415 | +0.484 | +123 / −94 |
| H1_错排前置 | 0.5 | 66.856 | +0.438 | +0.433 | +0.525 | +126 / −99 |
| C1_Top8 无条件硬负样本 | 0.5 | 66.845 | +0.428 | +0.452 | +0.608 | +165 / −139 |
| C3_按错排难度分层 | 0.5 | 66.813 | +0.395 | +0.432 | +0.535 | +124 / −100 |
| **B3_mixed（混合负样本）** | 0.5 | 66.726 | +0.309 | +0.283 | +0.353 | +96 / −77 |
| B2_hard（纯硬负样本） | 0.5 | 66.585 | +0.168 | +0.217 | +0.261 | +100 / −85 |

方法演进脉络很清晰：

1. **B2 纯硬负样本**：只 +0.17，且 R5 掉得比 R1 涨得多 —— 硬负样本把简单样本挤走了。
2. **B3 混合**：硬 + 随机按比例混合，+0.31，R5 稳住。**这是唯一做了 Test 独立验证的方案**。
3. **H1/H2 错排驱动**：不再按「特征距离」挖负样本，而是挖**「当前排序错误（负样本排在正样本前面）」**的那些，直接对症，+0.44。
4. **P1 排序保护**：对训练集里**原本就排对**的查询加保序惩罚，阻止硬负样本把它们带崩，+0.59 —— 单步增益最大的一步。
5. **S1 特征空间混合**：在特征空间里做同负身份插值，而不是只在图像层面挑，+0.55 且 mINP 最高。

**B3 的冻结 Test 独立验证（关键证据）**：B3 的 α 与分支选择全部在 val 上定死之后，才在 Test 上跑一次 —— Test R1 从 **66.374 → 66.515（α=0.5, +0.141）/ 66.585（α=1.0, +0.211）**，mAP 同步 +0.218 / +0.130。
增益从 val 的 +0.31 缩到 Test 的 +0.14，**说明 val 上确实有约一半是选择偏差**，但方向没变、符号没翻 —— 这已经是这套实验里最硬的证据了。

## 4. 有效实验（三）：排序质量方向（mAP / mINP 大涨，R1 不动）

这一类很有意思：**图的整体排序质量大幅改善，但 top-1 没变**。也就是「正样本往上爬了，但还不够爬到第一」。

| 方法 | R1 | ΔR1 | ΔmAP | ΔmINP |
|---|---|---|---|---|
| S_视觉三跳传播 | 64.891 | −1.526 | **+4.549** | **+12.002** |
| S_视觉双跳传播 | 65.590 | −0.828 | +4.417 | +10.810 |
| G4_多视角正证据传播 | 66.418 | 0.000 | +4.198 | +10.165 |
| G6_正证据 + Top1 竞争 | 66.613 | +0.195 | +4.187 | +10.144 |
| G3_多模态一致图传播 | 66.694 | +0.276 | +3.876 | +8.515 |
| G2_共同邻居结构传播 | 66.629 | +0.211 | +3.707 | +8.215 |
| C3_可信图互邻传播 | 66.466 | +0.049 | +3.451 | +7.654 |
| C4_保护 Top1 深层传播 | 66.418 | 0.000 | +3.353 | +7.546 |

引入图传播后，mINP 能涨 8~12 个点，说明「正确样本被拉到很前面」这件事是可以做到的；但 R1 不涨，说明**卡点不在排序质量，而在决策边界**。
`C4_保护 Top1` 是其中最有用的一条：**在完全不动 R1 的前提下白拿 +0.59 mAP / +1.78 mINP**，属于零风险增益，适合作为任何后续方法的免费插件。

## 5. 反例：走不通的方向

完整清单见 `results/bidirectional_complement/` 与 `results/summary_all.csv`（按 ΔR1 升序看尾部）。

| 方向 | 结果 | 结论 |
|---|---|---|
| **图文双向互补（23 个实验）** | 增益真实存在（+1.9 ~ +2.3），但**随机对照赢了** | 详见下方专节 |
| LoRA 微调编码器（A1/A2） | +0.011 / −0.043 | 1000 步内 LoRA 学不动，冻结编码器才是对的 |
| C1_Top8 无条件硬负样本 α=1.0 | **−0.606** | 硬负样本不能「全力」上，必须混合 + 保护 |
| 语义破坏型扰动 | −56.7 / −37.7 / −30.9 | 互换颜色词、删除颜色词、上下半身互换，直接把 CLIP 语义打碎 |
| 图库视觉拥挤惩罚 | −28.012 | 纯视觉密度先验与身份无关，是纯噪声 |
| 随机查询分桶 Sinkhorn | −4.612 | OT 平衡必须**全局**做，分桶会破坏容量约束 |
| 三值 / 符号二值编码 | −3.020 / −5.018 | 特征量化到 8bit 还行（+0.032），再低就崩 |
| 首末分句证据分解 | −25.9 ~ −43.0 | 分句级文本表示远弱于整句 |

### 专节：图文双向互补为什么不算成功

这一系列（`results/bidirectional_complement/`，23 个实验）用的是**独立的 `STANDARD_SINGLE_TEXT` 协议**，基线 R1 = **56.84**（官方 val 是 66.42），两套协议不可直接横向比较，但系列内部完全自洽。

单看数字它很漂亮 —— 实验02 的 `rank_selective` 拿到 **+2.046**，实验03 三种子平均 **+2.035±0.066**。问题是实验03 自己设的因果对照把结论推翻了：

| 方法（实验03，3 seeds 均值） | ΔR1 vs IRRA | ΔR1 vs rank |
|---|---|---|
| rank（多描述简单集成） | +1.895 | 0.000 |
| rank_same（同身份互补文本） | +2.008 | +0.114 |
| rank_cross（跨身份互补文本） | +2.073 | +0.179 |
| **rank_random（随机文本）** | **+2.133** | **+0.238** |
| rank_selective | +2.035 | +0.141 |

**随机文本 (+0.238) 打赢了跨身份互补 (+0.179)，也打赢了同身份互补 (+0.114)。**
也就是说，+2 点增益全部来自「多条描述集成平均」这个朴素效应，**一点也没来自「身份互补信息」**。补进来的文本是不是这个人、是不是互补，无关紧要 —— 这就证伪了整条路线的核心假设。

后续 exp04~exp23 用真实 caption、图库支持集、双层身份关联等 20 种方式试图把互补做出来，最好的一次（exp19）在 542 条 holdout 上净修正 **+4 条**（75.46% → 76.20%），完全在噪声范围内。

**这条路线我判断为死路**，但它排除了一个很有诱惑力的方向，价值就在这里。

**`B1_random` 对照臂的作用**：所有硬负样本方案都必须先超过 `B1_random`（同 800 步、随机负样本，ΔR1 在 −0.08 ~ +0.24 之间抖动）。B2/B3/H1/P1/S1 都显著超过它，所以增益**不是「多训了几百步」的副产物**。这一步筛掉的假阳性比任何单一调参都值钱。

## 7. 复现

脚本是**单文件自包含**的，路径常量在文件头部（`BEST_DIR`、`SOURCE_DIR`），本机跑之前改这两行即可：

```bash
# 训练侧（示例：S1 同身份特征混合）
python code/hard_negative/第十七步_同负身份特征空间困难负样本S1_B0与P1对照.py --self-test
python code/hard_negative/第十七步_同负身份特征空间困难负样本S1_B0与P1对照.py

# 推理侧（示例：第 5 轮，含 O_Sinkhorn 低温）
python code/inference_rounds/round5_cross_mechanism.py
```

依赖：`torch >= 1.8`、`numpy`、`scikit-learn`、CLIP 权重与 CUHK-PEDES 数据。
每步输出目录以时间戳命名，**绝不覆盖历史结果**；每个脚本都会写 `PID_Bootstrap` 配对置信区间。

## 8. 诚实性声明

这套实验里我自己最看重的一点，是**把「负结果」和「正结果」放在同一张表里**：

- 23 个图文双向互补实验全留在仓库里，**包括那个「随机文本对照打赢了互补文本」的对照表** —— 那张表直接推翻了这条路线的核心假设，删掉它这个仓库就变成了自吹。
- 所有推理侧单轮变体都标了「只在单轮出现过」，只有跨轮复现过的才进第 2 节主表。
- B3 的 val→Test 增益缩水一半这件事写在正文里，没有藏。
- `B1_val_batch_reference`（+0.94）标成 transductive 对照，明确不算方法。
- 图文双向互补的基线是 56.84 而非官方 66.42，协议不同这件事写在专节第一行。

如果只记一条结论：**在这个任务上，「测试时全局校准」和「保护已正确样本」比「引入更多模态信息」有效得多。**
